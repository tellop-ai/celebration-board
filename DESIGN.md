# Celebration board

Approved 2026-10-27: an uncluttered greeting board with a centered title, an introduction, signed message cards,
and a small action row. Three cards across in a wide window, two at a medium width, one on a phone. A second
reading layout centers one wider card per row. Content decides each card's height. Use the kit's display/body
fonts and semantic color pairs. Keep the kit tokens, fonts and pieces intact. Start light; the approved design
includes a visitor-pressed dark switch, only on html. Both languages fit without clipped controls.

Daily management uses PageFrame, CountsLine, AppMenu and DataTable. Message forms use Dialog with a bounded
height, scrollable fields and reachable actions. Personal pictures use PictureField, videos use FileUpload.
Slideshow pictures use contain; no autoplay sound or motion. AI drafts are separate proposals until accepted.
Local-only sharing notice is plain text, with no dead invite control.
